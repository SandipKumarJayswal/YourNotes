# YourNotes – Student Academic Portal

A responsive web platform that lets college students access and share academic study materials, organized subject-wise for quick and easy navigation.

## Features
- Subject-wise structured interface for organizing study materials
- Centralized system improving accessibility of notes for students
- Responsive design for seamless access across devices
- User-friendly navigation

## Tech Stack
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` directly in any browser
